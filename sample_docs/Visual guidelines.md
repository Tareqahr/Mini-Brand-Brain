# Celonis Visual Guidelines

## Brand Colors

### Primary Palette
- Celonis Black: #000000 — primary text, headlines, key UI elements, primary backgrounds
- Celonis White: #FFFFFF — page backgrounds, reversed text on dark surfaces
- Celonis Orange: #FF6600 — primary accent, CTAs, highlights, and key data callouts. Use sparingly — it should command attention, not fill space.

### Secondary Palette
- Cool Gray: #F5F5F0 — section backgrounds, card fills, content dividers
- Mid Gray: #888888 — secondary text, captions, metadata
- Dark Gray: #333333 — body text on light backgrounds
- Light Orange: #FFF0E6 — orange tint backgrounds for callout sections

### Usage Rules
- Never use orange as a background for large content areas
- Never place orange text on an orange background
- The primary orange should appear on no more than 10-15% of any given page
- Black and white are the workhorses — orange is the accent

## Typography

### Typefaces
- Primary: Neue Haas Grotesk Display — headlines, hero text, large callouts
- Secondary: Neue Haas Grotesk Text — body copy, UI text, captions
- Fallback: Inter (Google Fonts) — for digital and web contexts where Neue Haas is unavailable
- Monospace: JetBrains Mono — for code, data, and technical content only
- Never use decorative, script, or serif typefaces in brand communications

### Type Scale
- Hero headlines: 64-80px, Bold, tight tracking (-0.02em)
- Section headlines: 32-48px, Bold
- Subheadings: 20-24px, Medium
- Body text: 16-18px, Regular, line-height 1.6
- Captions and labels: 12-14px, Regular

## Logo Usage
- Minimum clear space: equal to the cap height of the "C" on all four sides
- Minimum digital size: 80px wide
- Never distort, rotate, recolor, or add effects to the logo
- Approved versions: black on white, white on black, black on orange (sparingly)
- Never place the logo on a busy photographic background
- Never recreate the logo in another typeface

## Photography Style
- Show real environments and real people doing real operational work
- Process-oriented imagery: operations floors, data dashboards, meetings where decisions are made
- Avoid stock photography clichés: no handshakes, no light bulbs, no generic smiling business people
- Color treatment: slightly desaturated with a warm, grounded tone
- Avoid overly staged or artificial compositions

## Iconography
- Line icons only — no filled or rounded icon styles
- Stroke weight: 1.5px at 24x24px base size
- Icons should be functional, not decorative
- Use the Celonis icon library; do not mix with third-party icon sets without approval
